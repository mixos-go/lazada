**Category:** Product Review API
**API:** GetReviewListByIdList

**Method:** GET
**HTTP Path:** /review/seller/list/v2

## API Description
get review list by id list, need get id list first

## Common Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| app_key | String | Yes | Unique app ID issued by LAZADA Open Platform console when you apply for an app category |
| timestamp | String | Yes | The time stamp of the request e.g. 1517820392000 (which translates to 5 February 2018 08:46:32) with less than 7200s difference from UTC time |
| access_token | String | Yes | API interface call credentials |
| sign_method | String | Yes | The HMAC hash algorithm you are using to calculate your signature |
| sign | String | Yes | Part of the authentication process that is used for identifying and verifying who is sending a request (click <a target='_blank' href='https://open.lazada.com/apps/doc/doc?nodeId=10450&docId=108068'>here</a> for details) |

## Request Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| id_list | Number[] | Yes | id list, maxLength = 10 |

## Response Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| data | Object | Yes | response data |
| data.review_list | Object[] | Yes | review list |
| data.review_list.submit_time | Number | Yes | the time when buyer submited this review |
| data.review_list.can_reply | Boolean | Yes | if review can be replied by seller |
| data.review_list.product_id | Number | Yes | Product Item ID |
| data.review_list.order_id | Number | Yes | Order ID |
| data.review_list.review_videos | Object[] | Yes | video list |
| data.review_list.review_videos.video_cover_url | String | Yes | cover image url |
| data.review_list.review_videos.video_url | String | Yes | video url |
| data.review_list.review_content | String | Yes | review content in text |
| data.review_list.ratings | Object | Yes | review ratings(only PRODUCT_REVIEW has ratings, FOLLOW_UP_REVIEWS doesn't have) |
| data.review_list.ratings.logistics_rating | Number | Yes | subRatings - logistics rating |
| data.review_list.ratings.overall_rating | Number | Yes | overall rating |
| data.review_list.ratings.seller_rating | Number | Yes | subRatings - seller rating |
| data.review_list.ratings.product_rating | Number | Yes | subRatings - product rating |
| data.review_list.review_type | String | Yes | PRODUCT_REVIEW or FOLLOW_UP_REVIEW. |
| data.review_list.id | Number | Yes | id |
| data.review_list.review_images | String[] | Yes | image url list |
| data.review_list.seller_reply | String | Yes | seller reply in text |
| data.review_list.create_time | Number | No | the time when review data created, this is the same with "start_time" and "end_time" in the request data of interface(/review/seller/history/list) |
| data.outdated_reviews | Number[] | Yes | id list if review is not exist or won't show(outdated/rejected) any more |
| success | Boolean | Yes | * |
| error_code | String | Yes | * |
| error_msg | String | Yes | * |
