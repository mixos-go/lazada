**Category:** Sponsored Solutions API
**API:** getCampaign

**Method:** GET/POST
**HTTP Path:** /sponsor/solutions/campaign/getCampaign

## API Description
Get campaign list with bizCode by seller.

## Common Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| app_key | String | Yes | Unique app ID issued by LAZADA Open Platform console when you apply for an app category |
| timestamp | String | Yes | The time stamp of the request e.g. 1517820392000 (which translates to 5 February 2018 08:46:32) with less than 7200s difference from UTC time |
| access_token | String | Yes | API interface call credentials |
| sign_method | String | Yes | The HMAC hash algorithm you are using to calculate your signature |
| sign | String | Yes | Part of the authentication process that is used for identifying and verifying who is sending a request (click <a target='_blank' href='https://open.lazada.com/apps/doc/doc?nodeId=10450&docId=108068'>here</a> for details) |

## Request Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| bizCode | String | Yes | Discovery:sponsoredSearch |
| campaignId | Number | Yes | 123 |

## Response Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| result | Object | Yes | The detail result, for this api is campaign detail info. |
| result.endDate | String | Yes | Campaign end date. |
| result.onlineStatus | Number | Yes | The campaign online status.1:Online;0:Offline;9:deleted. |
| result.campaignObjective | Number | Yes | Your campaign objective helps determine your bidding strategy - Traffic objective helps you to increase the number of clicks to your store, while sales objective helps to increase your store’s sales. |
| result.campaignType | Number | Yes | Unlock different ways to bids, select products, and keywords with campaign types. |
| result.campaignId | Number | Yes | Campaign id. |
| result.budgetUsedAmount | Number | Yes | Today used amount of daily budget. |
| result.autoItemSelect | Number | Yes | The way the product be selected.1:manual(I want to select products manually from my store.);2:auto(Let Lazada optimize the products within the campaigns in real-time to maximize the campaigns' performance) |
| result.haveAdCount | Number | Yes | The count of adgroup of this campaign. |
| result.startDate | String | Yes | Campaign start date. |
| result.switchStatus | Number | Yes | Is the campaign on rightnow.1:ON:0:OFF. |
| result.platform | Number[] | Yes | Placements determine where shoppers will see your promoted products. |
| result.sceneId | Number | Yes | Fine granularity to discriminate solutions.0:SD; |
| result.autoCreative | Number | Yes | Let Lazada automatically set creatives for your products.1:ON;0:OFF. |
| result.campaignModel | Number | Yes | To discriminate solutions.99:SD+NPL. |
| result.maxBid | String | Yes | Max bid determines the highest amount that you're willing to pay for a click on your promoted product. |
| result.dayBudget | String | Yes | Budget indicates the maximum amount you’re willing to pay each day. |
| result.campaignName | String | Yes | campaignName |
| success | String | Yes | System result for this api call. |
| errorMsg | String | No | If the api call failed, this field will show the detail reason. |
| analyseTraceId | String | No | If the api call failed, you could find us with this. |
