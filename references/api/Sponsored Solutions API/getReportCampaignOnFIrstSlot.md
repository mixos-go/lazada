**Category:** Sponsored Solutions API
**API:** getReportCampaignOnFIrstSlot

**Method:** GET/POST
**HTTP Path:** /sponsor/solutions/report/getReportCampaignOnPrePlacement

## API Description
Get sponsored discovery report campaign first slot

| Field | Type | Required | Description |
