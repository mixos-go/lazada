**Category:** FBL API
**API:** GetWarehouseStock

**Method:** GET
**HTTP Path:** /fbl/stocks/get

## API Description
Get SKU list and stock by warehouse code

## Common Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| app_key | String | Yes | Unique app ID issued by LAZADA Open Platform console when you apply for an app category |
| timestamp | String | Yes | The time stamp of the request e.g. 1517820392000 (which translates to 5 February 2018 08:46:32) with less than 7200s difference from UTC time |
| access_token | String | Yes | API interface call credentials |
| sign_method | String | Yes | The HMAC hash algorithm you are using to calculate your signature |
| sign | String | Yes | Part of the authentication process that is used for identifying and verifying who is sending a request (click <a target='_blank' href='https://open.lazada.com/apps/doc/doc?nodeId=10450&docId=108068'>here</a> for details) |

## Request Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| seller_sku | String | No | Seller SKU |
| marketplace | String | Yes | Marketplace should be "LAZADA_MY","LAZADA_ID","LAZADA_VN","LAZADA_SG","LAZADA_TH","LAZADA_PH" |
| fulfilment_sku | String | No | List of shop SKU, Comma separated list in square brackets |
| store_code | String | No | Warehouse Code List：https://www.yuque.com/u1990121/kb/exh5go#B4gg |

## Response Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| data | Object[] | No | Response body |
| data.fulfilment_sku | String | No | Shop SKU |
| data.store_stocks | Object[] | No | Stock Warehouse Detail |
| data.store_stocks.store_code | String | No | Warehouse Code |
| data.store_stocks.stocks | Object | No | Stock Items Detail |
| data.store_stocks.stocks.sellable | Object | No | Sellable Stock |
| data.store_stocks.stocks.sellable.available | Number | No | Sellable available Stock |
| data.store_stocks.stocks.sellable.reserved | Number | No | Sellable reserved Stocks |
| data.store_stocks.stocks.unsellable | Object | No | Unsellable Stock |
| data.store_stocks.stocks.unsellable.available | Number | No | Unsellable available Stock |
| data.store_stocks.stocks.unsellable.reserved | Number | No | Unsellable reserved Stocks |
| data.store_stocks.stocks.pending | Object | No | Pending Stock |
| data.store_stocks.stocks.pending.reserved | Number | No | Pending reserved Stocks |
| data.store_stocks.stocks.pending.available | Number | No | Pending available Stock |
