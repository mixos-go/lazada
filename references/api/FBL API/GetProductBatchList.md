**Category:** FBL API
**API:** GetProductBatchList

**Method:** GET/POST
**HTTP Path:** /fbl/product_batch/query

## API Description
query product batch list

## Common Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| app_key | String | Yes | Unique app ID issued by LAZADA Open Platform console when you apply for an app category |
| timestamp | String | Yes | The time stamp of the request e.g. 1517820392000 (which translates to 5 February 2018 08:46:32) with less than 7200s difference from UTC time |
| access_token | String | Yes | API interface call credentials |
| sign_method | String | Yes | The HMAC hash algorithm you are using to calculate your signature |
| sign | String | Yes | Part of the authentication process that is used for identifying and verifying who is sending a request (click <a target='_blank' href='https://open.lazada.com/apps/doc/doc?nodeId=10450&docId=108068'>here</a> for details) |

## Request Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| productBatchListRequest | Object | Yes | request body |
| productBatchListRequest.fulfillment_sku_ids | Number[] | Yes | fulfillment sku ids |
| productBatchListRequest.shipper_id | Number | Yes | shipper id |
| productBatchListRequest.page_no | Number | Yes | page no |
| productBatchListRequest.page_size | Number | Yes | page size |
| productBatchListRequest.store_code | String | Yes | store code |

## Response Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| result | Object | Yes | response body |
| result.data | Object | Yes | response body data |
| result.data.store_code | String | No | store code |
| result.data.batch_list | Object[] | No | batch list |
| result.data.batch_list.fulfillment_sku_id | Number | No | fulfillment sku id |
| result.data.batch_list.product_batch | Number | No | product batch id |
| result.data.batch_list.manufacturing_date | String | No | manufacturing date |
| result.data.batch_list.expiry_date | String | No | expiry date |
| result.data.batch_list.outbound_ban_date | String | No | outbound ban date |
| result.data.batch_list.inventory_status | Number | No | inventory status |
| result.data.batch_list.quantity | Number | No | quantity |
| result.data.page_no | Number | No | page no |
| result.data.page_size | Number | No | page size |
| result.success | Boolean | Yes | result |
| result.error_message | String | Yes | error message |
| result.error_code | String | Yes | error code |
