**Category:** FBL API
**API:** GetPlatformProductsV2

**Method:** GET
**HTTP Path:** /fbl/platform_products/get2

## API Description
Search products list

## Common Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| app_key | String | Yes | Unique app ID issued by LAZADA Open Platform console when you apply for an app category |
| timestamp | String | Yes | The time stamp of the request e.g. 1517820392000 (which translates to 5 February 2018 08:46:32) with less than 7200s difference from UTC time |
| access_token | String | Yes | API interface call credentials |
| sign_method | String | Yes | The HMAC hash algorithm you are using to calculate your signature |
| sign | String | Yes | Part of the authentication process that is used for identifying and verifying who is sending a request (click <a target='_blank' href='https://open.lazada.com/apps/doc/doc?nodeId=10450&docId=108068'>here</a> for details) |

## Request Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| per_page | Number | No | Maximum number of results Per Page |
| seller_id | Number | Yes | sellerId |
| marketplace | String | Yes | Marketplace |
| seller_sku | String | No | sellerSku |
| platform_sku_name | String | No | Platform SKU Name |
| ready_for_inbound | Boolean | No | Products that have binding stock in warsehouse |
| platform_sku | String | No | List of Platform SKU. Separate By Comma (,) |
| page | Number | No | Page Number |

## Response Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| data | Object[] | Yes | List of products data |
| data.platform_sku_name | String | Yes | Platform SKU Name |
| data.status | String | Yes | status from ASC |
| data.marketplace | String | Yes | marketplace Fields |
| data.source | String | Yes | source |
| data.product_id | String | Yes | productId |
| data.skus | Object[] | Yes | List of sku data |
| data.skus.fulfillment_sku_name | String | No | FulfillmentSkuName |
| data.skus.fulfillment_sku | String | No | FulfillmentSkuCode |
| data.skus.sku_status | String | No | status from ASC |
| data.skus.platform_sku | String | No | PlatformSkuCode |
| data.skus.seller_sku | String | No | sellerSku |
| data.skus.extend_fields | String | No | extend_fields |
