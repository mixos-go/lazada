**Category:** Instant Messaging API
**API:** GetMessages

**Method:** GET
**HTTP Path:** /im/message/list

## API Description
Get message list

## Common Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| app_key | String | Yes | Unique app ID issued by LAZADA Open Platform console when you apply for an app category |
| timestamp | String | Yes | The time stamp of the request e.g. 1517820392000 (which translates to 5 February 2018 08:46:32) with less than 7200s difference from UTC time |
| access_token | String | Yes | API interface call credentials |
| sign_method | String | Yes | The HMAC hash algorithm you are using to calculate your signature |
| sign | String | Yes | Part of the authentication process that is used for identifying and verifying who is sending a request (click <a target='_blank' href='https://open.lazada.com/apps/doc/doc?nodeId=10450&docId=108068'>here</a> for details) |

## Request Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| session_id | String | Yes | session id |
| start_time | Number | Yes | when request the first page pls input current timestamp，get the next page pls input previous page response field next_start_time |
| page_size | Number | Yes | page size |
| last_message_id | String | No | previous page output param [last_message_id];it could be null when get the first page, get the next page pls input previous page response field last_message_id |

## Response Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| err_code | String | Yes | error code |
| data | Object | Yes | json |
| data.message_list | Object[] | Yes | object list |
| data.message_list.from_account_type | Number | Yes | user type 1=buyer 2=seller;sender account type, 1 represents the buyer, 2 represents the seller |
| data.message_list.to_account_type | Number | Yes | user type 1=buyer 2=seller;receiver account type, 1 represents the buyer, 2 represents the seller |
| data.message_list.from_account_id | String | Yes | send msg user;sender account id |
| data.message_list.message_id | String | Yes | message id |
| data.message_list.to_account_id | String | Yes | receiver account id |
| data.message_list.site_id | String | Yes | country code ;SG/MY/TH/VN/PH/ID |
| data.message_list.session_id | String | Yes | session id |
| data.message_list.template_id | Number | Yes | message template;message template id, 1: normal text message 3: picture message 4: emoji message 10006: item message 10007: order message 10008: voucher message 10010: invite buyers to follow the store 6: video message, use this API to upload video (The video duration is greater than 3s and less tha |
| data.message_list.type | Number | Yes | 1=userSend 2=systemSend;1: message come from user 2: message come from system |
| data.message_list.content | String | Yes | template card json;session summary |
| data.message_list.send_time | Number | Yes | message send time |
| data.message_list.process_msg | String | No | If this field is not empty, it means that this message has not passed the security interception verification, which means that this message is only visible to the seller, and the ISV needs to display this prompt information to the seller on the screen |
| data.message_list.status | Number | No | 0: message status normal, 1: message has been recalled by sender |
| data.message_list.auto_reply | Boolean | No | true: it is a auto reply message. false: it is not a auto reply message |
| data.has_more | Boolean | Yes | has next page |
| data.next_start_time | Number | Yes | the begin timestamp of next page，When pulling the next page, it needs to be passed in as an input parameter |
| data.last_message_id | String | No | The ID of the last message on this page. When pulling the next page, it needs to be passed in as an input parameter |
| success | Boolean | Yes | result true or false |
| err_message | String | Yes | error message |
