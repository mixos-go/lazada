**Category:** Instant Messaging API
**API:** GetSessionDetail

**Method:** GET
**HTTP Path:** /im/session/get

## API Description
get session detail by sessionid

## Common Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| app_key | String | Yes | Unique app ID issued by LAZADA Open Platform console when you apply for an app category |
| timestamp | String | Yes | The time stamp of the request e.g. 1517820392000 (which translates to 5 February 2018 08:46:32) with less than 7200s difference from UTC time |
| access_token | String | Yes | API interface call credentials |
| sign_method | String | Yes | The HMAC hash algorithm you are using to calculate your signature |
| sign | String | Yes | Part of the authentication process that is used for identifying and verifying who is sending a request (click <a target='_blank' href='https://open.lazada.com/apps/doc/doc?nodeId=10450&docId=108068'>here</a> for details) |

## Request Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| session_id | String | Yes | session id |

## Response Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| err_code | String | Yes | error code 0=success |
| data | Object | Yes | json |
| data.summary | String | Yes | the summary of session |
| data.self_position | Number | Yes | self read time |
| data.to_position | Number | Yes | The other party's read time |
| data.head_url | String | Yes | user head picture url |
| data.unread_count | Number | Yes | unread count |
| data.last_message_time | Number | Yes | last message send time of session |
| data.last_message_id | String | Yes | last message id of session |
| data.session_id | String | Yes | session id |
| data.title | String | Yes | buyer nick name |
| data.buyer_id | Number | Yes | buyer user id |
| data.tags | String[] | No | the tag of session |
| data.site_id | String | No | country code |
| success | Boolean | Yes | result true or false |
| err_message | String | Yes | error message |
