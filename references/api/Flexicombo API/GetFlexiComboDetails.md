**Category:** Flexicombo API
**API:** GetFlexiComboDetails

**Method:** GET
**HTTP Path:** /promotion/flexicombo/details

## API Description
get promotion flexi combo detail by id

## Common Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| app_key | String | Yes | Unique app ID issued by LAZADA Open Platform console when you apply for an app category |
| timestamp | String | Yes | The time stamp of the request e.g. 1517820392000 (which translates to 5 February 2018 08:46:32) with less than 7200s difference from UTC time |
| access_token | String | Yes | API interface call credentials |
| sign_method | String | Yes | The HMAC hash algorithm you are using to calculate your signature |
| sign | String | Yes | Part of the authentication process that is used for identifying and verifying who is sending a request (click <a target='_blank' href='https://open.lazada.com/apps/doc/doc?nodeId=10450&docId=108068'>here</a> for details) |

## Request Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| id | Number | Yes | id |

## Response Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| data | Object | Yes | response body |
| data.order_used_numbers | Number | No | orders numbers that has been used in flexi combo |
| data.apply | String | Yes | apply scope: ENTIRE_SHOP \| SPECIFIC_PRODUCTS |
| data.sample_skus | Object[] | Yes | sample list |
| data.sample_skus.product_id | Number | No | sample product id |
| data.sample_skus.sku_id | Number | No | sample sku id |
| data.sample_skus.tier | Number | No | tier of the sample |
| data.criteria_type | String | Yes | criteria type: AMOUNT \| QUANTITY |
| data.type | String | Yes | fixed value: Flexi-combo |
| data.criteria_value | String[] | Yes | criteria value |
| data.order_numbers | Number | Yes | orders numbers that can use flexi combo |
| data.platform_channel | String | Yes | platform channel |
| data.name | String | Yes | name |
| data.gift_skus | Object[] | Yes | gift list |
| data.gift_skus.product_id | Number | No | gift product id |
| data.gift_skus.sku_id | Number | No | gift sku id |
| data.gift_skus.tier | Number | No | tier of the gift |
| data.discount_type | String | Yes | money \| discount \| freeGift \| freeSample \| discountWithGift \| moneyWithGift \| discountWithSample \| moneyWithSample |
| data.start_time | Number | Yes | flexi combo start time |
| data.end_time | Number | Yes | flexi combo end time |
| data.id | Number | Yes | id |
| data.discount_value | String[] | Yes | discount value |
| data.status | String | Yes | NOT_START \| ONGOING \| SUSPEND \| FINISH |
| data.stackable | Boolean | No | Stackable Discount，Ex. Buy 2SGD Save 1SGD, Buy 4SGD Save 2SGD, Buy 6SGD Save 3SGD, etc. |
| data.gift_buy_limit_value | String[] | No | buyer can choose gift/sample quantity limit value list |
| success | Boolean | Yes | true \| false |
| error_code | String | Yes | error code |
| error_msg | String | Yes | error message |
