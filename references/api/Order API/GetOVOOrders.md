**Category:** Order API
**API:** GetOVOOrders

**Method:** GET/POST
**HTTP Path:** /orders/ovo/get

## API Description
This interface is only applicable to the merchant side of the business and is used to set the maximum number of SKUs that certain merchants can sell per day

## Common Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| app_key | String | Yes | Unique app ID issued by LAZADA Open Platform console when you apply for an app category |
| timestamp | String | Yes | The time stamp of the request e.g. 1517820392000 (which translates to 5 February 2018 08:46:32) with less than 7200s difference from UTC time |
| access_token | String | Yes | API interface call credentials |
| sign_method | String | Yes | The HMAC hash algorithm you are using to calculate your signature |
| sign | String | Yes | Part of the authentication process that is used for identifying and verifying who is sending a request (click <a target='_blank' href='https://open.lazada.com/apps/doc/doc?nodeId=10450&docId=108068'>here</a> for details) |

## Request Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| tradeOrderIds | String | Yes | id |

## Response Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| result | Object | Yes | result |
| result.success | String | No | success or not |
| result.tradeOrders | Object[] | No | trader orders |
| result.tradeOrders.tradeOrderId | Number | No | trade order id |
| result.tradeOrders.paymentMethod | String | No | payment method |
| result.tradeOrders.paidTime | String | No | paid time |
| result.tradeOrders.tradeOrderLines | Object[] | No | trade OrderLines |
| result.tradeOrders.tradeOrderLines.tradeOrderLineId | Number | No | trade orderLine id |
| result.tradeOrders.tradeOrderLines.deliveryStatus | String | No | delivery status |
| result.tradeOrders.tradeOrderLines.reverseStatus | String | No | reverse status |
| result.tradeOrders.tradeOrderLines.deliveredTime | String | No | delivered time |
| result.errorCode | String | No | error code |
