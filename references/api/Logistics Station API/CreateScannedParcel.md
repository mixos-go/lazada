**Category:** Logistics Station API
**API:** CreateScannedParcel

**Method:** POST
**HTTP Path:** /logistics/station/v1/scanned-parcels/create

## API Description
Create a scanned parcel. Call this API when scanning the tracking number on the parcel.

## Common Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| app_key | String | Yes | Unique app ID issued by LAZADA Open Platform console when you apply for an app category |
| timestamp | String | Yes | The time stamp of the request e.g. 1517820392000 (which translates to 5 February 2018 08:46:32) with less than 7200s difference from UTC time |
| access_token | String | No | API interface call credentials |
| sign_method | String | Yes | The HMAC hash algorithm you are using to calculate your signature |
| sign | String | Yes | Part of the authentication process that is used for identifying and verifying who is sending a request (click <a target='_blank' href='https://open.lazada.com/apps/doc/doc?nodeId=10450&docId=108068'>here</a> for details) |

## Request Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| stationId | String | Yes | Station ID in partner system |
| cageNumber | String | No | Cage number. If cage number is present, it will be validated. In case missing cage number, the system will choose default cage number |
| trackingNumber | String | Yes | Tracking number of parcel |
| serviceType | String | Yes | Accept values: SELLER_DROPOFF, CUSTOMER_DROPOFF (Customer return), CUSTOMER_COLLECTION (Collection point) |

## Response Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| success | Boolean | No | Is success? |
| data | Object | No | Response data |
| data.trackingNumber | String | No | Tracking number |
| data.cageNumber | String | No | Cage number |
| data.sellerName | String | No | [SELLER_DROPOFF/CUSTOMER-DROPOFF] Seller name |
| data.pickupTplSlug | String | No | [SELLER_DROPOFF/CUSTOMER-DROPOFF] Pickup 3PL slug: lex-th for regular parcels, another 3PL in case MPU |
| data.createdAt | Number | No | Created at timestamp in milliseconds |
| data.lastmileTpl | String | No | [CUSTOMER_COLLECTION] Lastmile 3PL name: LEX TH, LEX VN, etc |
| data.warningMessage | String | No | [CUSTOMER_COLLECTION] Warning message in case parcel is SLA breached |
| data.serviceType | String | No | Service type |
| errorCode | String | No | Error code |
| errorMsg | String | No | Error message |
| traceId | String | No | Trace id for debugging |
