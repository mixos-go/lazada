**Category:** Finance API
**API:** GetPayoutStatus

**Method:** GET
**HTTP Path:** /finance/payout/status/get

## API Description
Get your transaction statements created after the provided date

## Common Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| app_key | String | Yes | Unique app ID issued by LAZADA Open Platform console when you apply for an app category |
| timestamp | String | Yes | The time stamp of the request e.g. 1517820392000 (which translates to 5 February 2018 08:46:32) with less than 7200s difference from UTC time |
| access_token | String | Yes | API interface call credentials |
| sign_method | String | Yes | The HMAC hash algorithm you are using to calculate your signature |
| sign | String | Yes | Part of the authentication process that is used for identifying and verifying who is sending a request (click <a target='_blank' href='https://open.lazada.com/apps/doc/doc?nodeId=10450&docId=108068'>here</a> for details) |

## Request Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| created_after | String | Yes | Filter statements created after the provided date. Mandatory. |

## Response Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| data | Object[] | Yes | Response body |
| data.closing_balance | String | No | Closing balance |
| data.guarantee_deposit | String | No | Guarantee deposit |
| data.payout | String | No | Amount to be paid out to seller for statement |
| data.paid | String | No | Payout status of statement. 1 is paid, and 0 is not paid |
| data.statement_number | String | No | Statement identifier |
| data.created_at | String | No | When the statement was created |
| data.updated_at | String | No | When the statement was last updated |
| data.opening_balance | String | No | The opening balance |
| data.item_revenue | String | No | The revenue generated by the item |
| data.shipment_fee | String | No | Costs of shipping |
| data.shipment_fee_credit | String | No | Shipping fee credit, if any |
| data.other_revenue_total | String | No | Other total revenue |
| data.fees_total | String | No | Sum of payment fee and return to seller fee |
| data.subtotal1 | String | No | Sum of item revenue and other revenue |
| data.refunds | String | No | Sum of all refunds, if any |
| data.fees_on_refunds_total | String | No | Accumulated fees on refunds issued |
| data.subtotal2 | String | No | (Sum of Subtotal1) - Refunds |
