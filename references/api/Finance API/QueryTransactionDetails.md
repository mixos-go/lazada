**Category:** Finance API
**API:** QueryTransactionDetails

**Method:** GET
**HTTP Path:** /finance/transaction/details/get

## API Description
API to query seller transaction details within specific date range.

## Common Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| app_key | String | Yes | Unique app ID issued by LAZADA Open Platform console when you apply for an app category |
| timestamp | String | Yes | The time stamp of the request e.g. 1517820392000 (which translates to 5 February 2018 08:46:32) with less than 7200s difference from UTC time |
| access_token | String | Yes | API interface call credentials |
| sign_method | String | Yes | The HMAC hash algorithm you are using to calculate your signature |
| sign | String | Yes | Part of the authentication process that is used for identifying and verifying who is sending a request (click <a target='_blank' href='https://open.lazada.com/apps/doc/doc?nodeId=10450&docId=108068'>here</a> for details) |

## Request Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| offset | String | No | Number of transaction lines to skip at the beginning of the list. |
| trans_type | String | No | Transaction type ID. |
| trade_order_id | String | No | Order ID. |
| limit | String | No | Number of lines of transactions to be extracted. The supported maximum number is 500. |
| start_time | String | Yes | Starting date when transactions need to be extracted. |
| end_time | String | Yes | Ending date when transactions need to be extracted. |
| trade_order_line_id | String | No | Order Item ID. |

## Response Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| data | Object[] | Yes | Response body |
| data.fee_type | String | No | Transaction type ID. |
| data.details | String | No | Transaction details |
| data.seller_sku | String | No | The seller SKU |
| data.lazada_sku | String | No | The Lazada SKU |
| data.amount | String | No | Total transaction value |
| data.VAT_in_amount | String | No | The VAT in amount |
| data.WHT_amount | String | No | The WHT amount |
| data.WHT_included_in_amount | String | No | The WHT included in amount or not |
| data.statement | String | No | Statement ID |
| data.paid_status | String | No | Yes / No |
| data.order_no | String | No | Order ID |
| data.orderItem_no | String | No | Order item number |
| data.orderItem_status | String | No | The order item status |
| data.shipping_provider | String | No | The shipping provider |
| data.shipping_speed | String | No | The shipping speed |
| data.shipment_type | String | No | The shipment type |
| data.reference | String | No | The Order Item ID (the Sub-order ID of "Order ID" parameter) |
| data.comment | String | No | Comments by regional finance team |
| data.payment_ref_id | String | No | Payment reference ID from bank or other payment provider |
| data.fee_name | String | No | feeName |
| data.transaction_date | String | No | Date of the transaction |
| data.transaction_type | String | No | Transaction type or fee name |
| data.transaction_number | String | No | Unique ID of the transaction in the format "Seller code- xxxxxxx" |
