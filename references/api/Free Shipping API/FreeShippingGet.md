**Category:** Free Shipping API
**API:** FreeShippingGet

**Method:** GET
**HTTP Path:** /promotion/freeshipping/get

## API Description
get free shipping promotion

## Common Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| app_key | String | Yes | Unique app ID issued by LAZADA Open Platform console when you apply for an app category |
| timestamp | String | Yes | The time stamp of the request e.g. 1517820392000 (which translates to 5 February 2018 08:46:32) with less than 7200s difference from UTC time |
| access_token | String | Yes | API interface call credentials |
| sign_method | String | Yes | The HMAC hash algorithm you are using to calculate your signature |
| sign | String | Yes | Part of the authentication process that is used for identifying and verifying who is sending a request (click <a target='_blank' href='https://open.lazada.com/apps/doc/doc?nodeId=10450&docId=108068'>here</a> for details) |

## Request Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| id | Number | Yes | promotion id |

## Response Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| data | Object | Yes | response body |
| data.template_type | String | Yes | template type, MANUALLY \| CAMPAIGN \| TEMPLATE |
| data.budget_type | String | Yes | UNLIMITED_BUDGET \| LIMITED_BUDGET |
| data.used_budget_value | String | Yes | used budget value |
| data.apply | String | Yes | apply scope: ENTIRE_SHOP \| SPECIFIC_PRODUCTS \| CAMPAIGN_PRODUCTS |
| data.period_end_time | Number | Yes | when specific period required, the period end time that this promotion takes effect (timestamp) |
| data.template_code | String | Yes | template code, when TEMPLATE type not null |
| data.category_name | String | Yes | category name |
| data.budget_value | String | Yes | budget value |
| data.promotion_name | String | Yes | promotion name |
| data.period_type | String | Yes | LONG_TERM \| SPECIAL_PERIOD |
| data.region_type | String | Yes | ALL_REGIONS \| SPECIAL_REGIONS |
| data.period_start_time | Number | Yes | when specific period required, the period start time that this promotion takes effect (timestamp) |
| data.platform_channel | String | Yes | LAZADA \| ZAL \| ALL_CHANNEL |
| data.campaign_tag | String | Yes | when CAMPAIGN template type and CAMPAIGN_PRODUCTS apply type not null |
| data.region_value | String[] | Yes | when SPECIAL_REGIONS not null |
| data.currency | String | Yes | currency |
| data.id | Number | Yes | promotion id |
| data.delivery_option | String | Yes | delivery option |
| data.promo_tier | Object | Yes | promotion tier |
| data.promo_tier.tiers | Object[] | Yes | promotion tier list |
| data.promo_tier.tiers.filter | String | Yes | deal criteria value |
| data.promo_tier.tiers.result | String | Yes | when partial subsidy discount type required，shipping fee subsidy value |
| data.promo_tier.discount_type | String | Yes | shipping fee subsidy type,FULL_SUBSIDY\|PARTIAL_SUBSIDY |
| data.promo_tier.deal_criteria | String | Yes | the criteria that customer can enjoy shipping fee subsidy, MONEY_VALUE_FROM_X\|ITEM_QUANTITY_FROM_X\|NO_CONDITION |
| data.status | String | Yes | status, NOT_START \| ONGOING \| SUSPEND \| FINISH |
| success | Boolean | Yes | true \| false |
| error_code | String | Yes | error code |
| error_msg | String | Yes | error message |
