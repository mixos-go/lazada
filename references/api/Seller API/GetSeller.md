**Category:** Seller API
**API:** GetSeller

**Method:** GET
**HTTP Path:** /seller/get

## API Description
Get seller information by current seller ID.

## Common Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| app_key | String | Yes | Unique app ID issued by LAZADA Open Platform console when you apply for an app category |
| timestamp | String | Yes | The time stamp of the request e.g. 1517820392000 (which translates to 5 February 2018 08:46:32) with less than 7200s difference from UTC time |
| access_token | String | Yes | API interface call credentials |
| sign_method | String | Yes | The HMAC hash algorithm you are using to calculate your signature |
| sign | String | Yes | Part of the authentication process that is used for identifying and verifying who is sending a request (click <a target='_blank' href='https://open.lazada.com/apps/doc/doc?nodeId=10450&docId=108068'>here</a> for details) |

## Response Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| data | Object | Yes | Response data |
| data.name_company | String | Yes | Company name |
| data.seller_id | Number | Yes | Seller's ID |
| data.name | String | Yes | Shop name |
| data.short_code | String | Yes | Seller's short code |
| data.logo_url | String | Yes | Logo URL |
| data.email | String | Yes | Seller's email |
| data.cb | Boolean | Yes | Whether the seller is a Cross Border seller or not |
| data.location | String | No | location of seller |
| data.status | String | No | three status ACTIVE INACTIVE DELETED |
| data.verified | Boolean | No | Whether the seller is verified |
| data.marketplaceEaseMode | Boolean | No | Whether the seller is MarketplaceEaseMode |
