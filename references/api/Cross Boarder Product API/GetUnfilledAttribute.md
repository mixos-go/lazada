**Category:** Cross Boarder Product API
**API:** GetUnfilledAttribute

**Method:** GET
**HTTP Path:** /product/global/unfilled/attribute/get

## API Description
get the product which have attribute not filled （for cross boarder sellers Only）

## Common Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| app_key | String | Yes | Unique app ID issued by LAZADA Open Platform console when you apply for an app category |
| timestamp | String | Yes | The time stamp of the request e.g. 1517820392000 (which translates to 5 February 2018 08:46:32) with less than 7200s difference from UTC time |
| access_token | String | Yes | API interface call credentials |
| sign_method | String | Yes | The HMAC hash algorithm you are using to calculate your signature |
| sign | String | Yes | Part of the authentication process that is used for identifying and verifying who is sending a request (click <a target='_blank' href='https://open.lazada.com/apps/doc/doc?nodeId=10450&docId=108068'>here</a> for details) |

## Request Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| offset | Number | Yes | offset |
| limit | Number | Yes | pageSize |
| attributeTag | String | Yes | only support key_prop |

## Response Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| data | Object | Yes | response body |
| data.total_products | Number | Yes | total numbers |
| data.products | Object[] | Yes | products |
| data.products.item_id | Number | Yes | product id |
| data.products.primary_category | Number | Yes | category id |
| data.products.seller_sku | String | Yes | seller sku |
| data.products.attributes | Object[] | Yes | all attributes |
| data.products.attributes.advanced | Object | Yes | 1: key attribute |
| data.products.attributes.advanced.is_key_prop | Number | Yes | 1: key attribute |
| data.products.attributes.input_type | String | Yes | text |
| data.products.attributes.options | String[] | Yes | all values |
| data.products.attributes.name | String | Yes | key name |
| data.products.attributes.is_mandatory | Number | Yes | 1: mandatory |
| data.products.attributes.attribute_type | String | Yes | normal |
| data.products.attributes.label | String | Yes | attritebu label |
| success | Boolean | Yes | success or false |
| error_detail | String | Yes | error detail |
| error_code | String | Yes | error code |
| errors | String | Yes | errors |
| error_msg | String | Yes | error msg |
