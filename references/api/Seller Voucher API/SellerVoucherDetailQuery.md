**Category:** Seller Voucher API
**API:** SellerVoucherDetailQuery

**Method:** GET
**HTTP Path:** /promotion/voucher/get

## API Description
get a seller voucher promotion detail

## Common Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| app_key | String | Yes | Unique app ID issued by LAZADA Open Platform console when you apply for an app category |
| timestamp | String | Yes | The time stamp of the request e.g. 1517820392000 (which translates to 5 February 2018 08:46:32) with less than 7200s difference from UTC time |
| access_token | String | Yes | API interface call credentials |
| sign_method | String | Yes | The HMAC hash algorithm you are using to calculate your signature |
| sign | String | Yes | Part of the authentication process that is used for identifying and verifying who is sending a request (click <a target='_blank' href='https://open.lazada.com/apps/doc/doc?nodeId=10450&docId=108068'>here</a> for details) |

## Request Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| voucher_type | String | Yes | voucher type COLLECTIBLE_VOUCHER \| CODE_VOUCHER |
| id | Number | Yes | promotion ID |

## Response Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| data | Object | Yes | response body |
| data.criteria_over_money | String | Yes | Discount details, if order value reaches set value, will money discount or percentage discount |
| data.apply | String | Yes | apply scope: ENTIRE_SHOP \| SPECIFIC_PRODUCTS |
| data.voucher_type | String | Yes | Voucher type, COLLECTIBLE_VOUCHER \| CODE_VOUCHER |
| data.collect_start | Number | Yes | The time that customers can collect the voucher |
| data.display_area | String | Yes | The area that customers can see the voucher. REGULAR_CHANNEL\|STORE_FOLLOWER\|OFFLINE\|LIVE_STREAM\|SHARE_VOUCHER\|CEM_SELLER |
| data.period_end_time | Number | Yes | The period end time that customers can use the voucher |
| data.voucher_name | String | Yes | Voucher name |
| data.voucher_discount_type | String | Yes | Discount type |
| data.offering_money_value_off | String | Yes | Discount details, if order value reaches criteria_over_money value, will discount money value |
| data.period_start_time | Number | Yes | The period start time that customers can use the voucher |
| data.limit | Number | Yes | Voucher limit per customer |
| data.order_used_budget | String | Yes | Already used total |
| data.currency | String | Yes | Currency |
| data.id | Number | Yes | Promotion ID |
| data.issued | Number | Yes | Revision should be greater than the current setting |
| data.max_discount_offering_money_value | String | Yes | Discount details, if order value reaches criteria_over_money value, allow maximum discount per order, just support percentage discount off type |
| data.voucher_code | String | Yes | Voucher code |
| data.offering_percentage_discount_off | String | Yes | Discount details, if order value reaches criteria_over_money value, will percentage discount off value |
| data.status | String | Yes | Promotin status, NOT_START \| ONGOING \| SUSPEND \| FINISH |
| success | Boolean | Yes | true \| false |
| error_code | String | Yes | error code |
| error_msg | String | Yes | error message |
