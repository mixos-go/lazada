**Category:** Product API
**API:** GetBrandByPages

**Method:** GET/POST
**HTTP Path:** /category/brands/query

## API Description
Use this API to retrieve all product brands by page index in the system.

## Common Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| app_key | String | Yes | Unique app ID issued by LAZADA Open Platform console when you apply for an app category |
| timestamp | String | Yes | The time stamp of the request e.g. 1517820392000 (which translates to 5 February 2018 08:46:32) with less than 7200s difference from UTC time |
| access_token | String | No | API interface call credentials |
| sign_method | String | Yes | The HMAC hash algorithm you are using to calculate your signature |
| sign | String | Yes | Part of the authentication process that is used for identifying and verifying who is sending a request (click <a target='_blank' href='https://open.lazada.com/apps/doc/doc?nodeId=10450&docId=108068'>here</a> for details) |

## Request Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| startRow | String | Yes | Number of brands to skip (i.e., an offset into the result set; together with the "limit" parameter, simple result set paging is possible; if you do page through results, note that the list of brands might change during paging). |
| pageSize | String | Yes | The maximum number of brands that can be returned. If you omit this parameter, the default of 40 is used. The Maximum is 200. |

## Response Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| data | Object | Yes | Response data |
| data.start_row | Number | Yes | start row |
| data.page_index | Number | Yes | page index |
| data.total_page | Number | Yes | total page (no use) |
| data.module | Object[] | Yes | data module |
| data.module.global_identifier | String | Yes | A unique string identifier for the brand across different systems. For example: ADIDAS, NIKE, APPLE. |
| data.module.name_en | String | Yes | The English name of the brand. |
| data.module.brand_id | Number | Yes | brand id |
| data.module.name | String | Yes | The actual name of the brand. |
| data.enable_total | Boolean | Yes | enable total or not (no use) |
| data.page_size | Number | Yes | page size |
| data.total_record | Number | Yes | total number of record |
| success | Boolean | Yes | operation success or not |
| error_code | String | Yes | error code |
| error_msg | String | Yes | error message |
