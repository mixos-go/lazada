**Category:** Product API
**API:** GetCategoryAttributes

**Method:** GET
**HTTP Path:** /category/attributes/get

## API Description
Use this API to get a list of attributes for a specified product category.

## Common Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| app_key | String | Yes | Unique app ID issued by LAZADA Open Platform console when you apply for an app category |
| timestamp | String | Yes | The time stamp of the request e.g. 1517820392000 (which translates to 5 February 2018 08:46:32) with less than 7200s difference from UTC time |
| access_token | String | No | API interface call credentials |
| sign_method | String | Yes | The HMAC hash algorithm you are using to calculate your signature |
| sign | String | Yes | Part of the authentication process that is used for identifying and verifying who is sending a request (click <a target='_blank' href='https://open.lazada.com/apps/doc/doc?nodeId=10450&docId=108068'>here</a> for details) |

## Request Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| primary_category_id | String | Yes | identifiers of category code |
| language_code | String | No | Language code indicates the type of language you would like to translate. Please note not all languages are available in every region. For example, in Indonesia, only English and Indonesia are available. If you are passing a language code which does not belong to your area, null value might receive. |

## Response Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| data | Object[] | No | Response body |
| data.advanced | Object | No | When the attribute is key attribute, is_key_prop = 1. When the attribute is not key attribute, is_key_prop = 0. |
| data.label | String | No | Human-readable display name of the attribute |
| data.name | String | No | Name of the attribute |
| data.is_mandatory | Number | No | Whether the attribute is mandatory |
| data.attribute_type | String | No | Attribute type |
| data.input_type | String | No | Attribute input type (text, date,numeric,img,rich text, singleSelect，multiSelect,enumInput,multiEnumInput) multiEnumInput/multiEnumInput supports custom value |
| data.options | Object[] | No | List of all option nodes |
| data.options.name | String | No | Option name |
| data.options.en_name | String | No | Option name in English |
| data.options.id | Number | No | options id |
| data.is_sale_prop | Number | No | Whether the attribute is sale property |
| data.id | Number | No | attribute id |
| data.unit | Object | No | { "precision": 1, "type": [ "inch", "cm" ], "numericMin": "1", "numericMax": "999" } |
| data.unit.type | String[] | No | [ "inch", "cm" ] |
| data.unit.numericMin | String | No | 1 |
| data.unit.numericMax | String | No | 999 |
| data.unit.precision | Number | No | 0 |
