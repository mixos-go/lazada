**Category:** Product API
**API:** GetProductContentScore

**Method:** GET/POST
**HTTP Path:** /product/content/score/get

## API Description
get product content score

## Common Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| app_key | String | Yes | Unique app ID issued by LAZADA Open Platform console when you apply for an app category |
| timestamp | String | Yes | The time stamp of the request e.g. 1517820392000 (which translates to 5 February 2018 08:46:32) with less than 7200s difference from UTC time |
| access_token | String | Yes | API interface call credentials |
| sign_method | String | Yes | The HMAC hash algorithm you are using to calculate your signature |
| sign | String | Yes | Part of the authentication process that is used for identifying and verifying who is sending a request (click <a target='_blank' href='https://open.lazada.com/apps/doc/doc?nodeId=10450&docId=108068'>here</a> for details) |

## Request Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| item_id | Number | Yes | Call this API; "Item Id" must be selected as the request parameter. |

## Response Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| result | Object | Yes | Result |
| result.data | Object | Yes | Response body |
| result.data.productTitle | String | No | Product title |
| result.data.score | Number | No | Product's latest content score |
| result.data.image | String | No | The main image of the selected product for a quick product information summary |
| result.data.total | Number | No | The total full content score |
| result.data.productId | Number | No | Product ID |
| result.data.items | Object[] | No | Issue list that need to be optimized of the selected product |
| result.data.items.key | String | No | Unique key to identify each issue |
| result.data.items.score | Number | No | The current score got in this issue |
| result.data.items.total | Number | No | The total score of this issue |
| result.data.items.group | String | No | Indicates the group of the issue, such as Content Completeness and Content Quality name The name of each issue to be displayed to sellers. |
| result.data.items.label | String | No | The extra high-level guidance and suggestion for this issue. |
| result.data.items.latest | Boolean | No | Optional field. Will only return for certain issues which need offline calculation. Value "false" means this issue has been optimized but still under system calculation and may update in 2 days. |
| result.data.items.indicators | Object[] | No | Optional field. Some extra details (usually for sub issues) and will only return for certain issues. Please check API response examples for more information. |
| result.data.items.indicators.critical | Boolean | No | To mark the critical issues which leads to 0 product score and represents potential content policy violations |
| result.data.items.indicators.text | String | No | Detailed name and description of the sub issue. |
| result.data.items.indicators.key | String | No | Unique key of the sub issue. |
| result.data.items.imageList | Object[] | No | Optional field. Only available for product with Image Quality issue. List the issue and image breakdown. |
| result.data.items.imageList.score | Number | No | The score of each image. |
| result.data.items.imageList.imageUrl | String | No | The url of the image with image quality issue |
| result.data.items.imageList.text | String | No | The image name, e.g product image/SKU image/long image/square image. |
| result.data.items.imageList.type | String | No | The score level of each image, e.g. low/moderate. This level is mapped to score. |
| result.data.items.imageList.imageType | Number | No | The enum of image type, e.g product image/SKU image/long image/square image. |
| result.data.items.imageList.indicators | Object[] | No | Optional field. Some extra details (usually for sub issues) and will only return for certain issues. Please check API response examples for more information. |
| result.data.items.imageList.indicators.text | String | No | Detailed name and description of the sub issue. |
| result.data.items.imageList.indicators.key | String | No | Unique key of the sub issue. |
| result.data.items.itemTitle | String | No | The name of each issue to be displayed to sellers. |
