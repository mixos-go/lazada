**Category:** Early Bird Price API
**API:** EarlyBirdActivityIsWhitelistSeller

**Method:** POST
**HTTP Path:** /activity/early/bird/isWhitelistSeller

## API Description
is whitelist seller for early bird acivity

| app_key | String | Yes | Unique app ID issued by LAZADA Open Platform console when you apply for an app category |

| result.module | Object | Yes | true or false, true is whitelist seller |
